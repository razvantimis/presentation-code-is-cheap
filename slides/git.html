04 · GIT KEEPS PROGRESS

Sessions die. Commits don’t.

1 worktree per task

1 commit per green step

1 draft PR from the first push

Fourth: agents crash, contexts fill up, laptops sleep. So git is the save system. Every task gets its own worktree, so several agents can work on the same repo at once. Every green step is a commit, WIP commits included, and the first push opens a draft PR. See the lightning: when a session crashes, I lose one step, never the ticket. A new session picks up from the last commit.
