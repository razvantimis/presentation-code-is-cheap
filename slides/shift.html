THE SHIFT

My job moved from typing code to deciding and proving.

Code got cheap. Decisions, memory and proof did not.

Here’s the mental model. An agent is a very fast junior that forgets everything between sessions. Watch the scale: typing code barely weighs anything now. What’s heavy is deciding what to build, remembering what we learned, and proving it works. So three things are scarce: clear decisions before code, memory that survives between sessions, and proof. Every habit I’ll show you is one of those three.
