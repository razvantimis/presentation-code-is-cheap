Code is cheap.
Design is not.

How I work with agents, now that they write most of my code.

Razvan Timis · Senior Full-Stack Developer

timis.dev ↗

Hi, I’m Razvan, you can find me at timis.dev. For the last year most of the code I ship has been typed by agents, often a few at once, like on the right: a lead session, an owner thread, a spec session. This isn’t a tool tour. In the next few minutes I want to show the handful of habits that made agents reliable for me, and the one idea behind all of them: code got cheap, so the scarce work moved to design and to proving things work.
