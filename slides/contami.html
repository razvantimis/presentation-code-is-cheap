THE EXAMPLE · CONTAMI, MY SAAS

Rewrite every htmx screen in React, without breaking a URL

GOAL

Every screen moves to React. The old UI gets deleted.

DONE MEANS

Story tests green, axe 0 violations, 4 sizes in light and dark.

SO FAR

1,041 PRs merged in the last 2 weeks. Removing the old UI has started.

Here’s the example I’ll use for the rest of the talk, because it’s real. Contami is my SaaS for Romanian accounting. Its UI was 165 server-rendered templates with htmx and Alpine. On 31 October I decided to move it to React, one screen at a time: the proxy sends a path to the new app when its screen is ready, so no URL changes and every step can be rolled back. The goal is clear, and so is “done”: story tests in a real browser, zero axe violations, every size in light and dark. In the last two weeks alone, agents merged over a thousand PRs into the new repo, and we’ve started deleting the old UI.
