Fifth, and the habit that lets me step back: the agent proves its own work with tools, not with words. On Contami, one command, pnpm ready, runs seven checks: the route tree, lint and types, the API contract, unit tests, story tests in a real browser with axe, the build, and the bundle budget. When one goes red, the agent reads the output, fixes it and runs it again. I never see the red. The lint has 41 rules, 24 of them our own, and many close the shortcuts: no skipping a test, no raising a test timeout, no disabling a rule without a reason. Then a fresh agent drives the app on video, and another agent that didn’t build the screen scores the UX. What reaches me is a draft PR with the evidence. If a check can run in a CLI, the agent runs it, not me.
