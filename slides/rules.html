## How to work

- A question is not a change request.

- Prefer small, reviewable changes.

- Never estimate work in human time.

- Code is cheap, design is not.

- No dead code, no TODO litter.

- Run tests before claiming done.

One repo in git. install.sh links the rules and skills into each agent.

01 · ONE BRAIN, EVERY AGENT

One AGENTS.md, shared by every tool

The first thing: one instructions file. Mine is AGENTS.md in a repo called dotagents. It says who I am, how I like code, and what done means. An install script wires it into every agent I use: Codex and opencode get a symlink, Claude Code imports it, and the rest get the skills. So switching tools doesn’t reset my standards. My favourite rule: a question is not a change request. If I ask “why is this slow?”, I want an answer, not a 400-line diff.
