01 · ONE BRAIN, EVERY AGENT, EVERY REPO

My own AGENTS.md, in every tool

The first thing: one global instructions file. Not a project’s AGENTS.md, mine. It lives in my home folder, in a git repo called dotagents, and loads in every project I open. It says who the agent is: Fred, my best colleague, who pushes back when I’m wrong. It says who I am, so it skips the basics. And it says how I like code and what done means. A repo can add its own AGENTS.md on top, and the repo wins on conflicts. An install script wires it into every agent I use: Codex and opencode get a symlink, Claude Code imports it, and the rest get the skills. So switching tools doesn’t reset my standards. My favourite rule: a question is not a change request. If I ask “why is this slow?”, I want an answer, not a 400-line diff.
